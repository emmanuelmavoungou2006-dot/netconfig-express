# 🚀 NetConfig Express

Calculateur IP et générateur de scripts Cisco CLI, pensé pour simplifier les TP réseaux.

## 🎬 Démonstration Vidéo

[![Regarder la vidéo de présentation](https://img.shields.io/badge/Regarder-la%20d%C3%A9mo-blue?style=for-the-badge&logo=youtube)](https://emmanuelmavoungou2006-dot.github.io/netconfig-express/)

---

## 🛠️ Fonctionnalités
- **Calcul automatique de sous-réseaux IPv4** (masques, adresses de broadcast, nombre d'hôtes utiles).
- **Génération instantanée de scripts Cisco commentés** (routeurs, interfaces, VLANs, et activation du serveur DHCP).
- **Interface web rapide et intuitive**, prête à l'emploi.
